# Dossier sounds — Assets audio du jeu

Placez vos fichiers audio ici avec les noms suivants :

| Fichier           | Description                        | Format recommandé |
|-------------------|------------------------------------|-------------------|
| background.mp3    | Musique de fond (jouée en boucle)  | MP3 128kbps+      |
| victory.mp3       | Son joué lors d'une victoire       | MP3 128kbps+      |
| defeat.mp3        | Son joué lors d'une défaite        | MP3 128kbps+      |
| correct.mp3       | Son pour lettre correcte           | MP3 court (< 1s)  |
| wrong.mp3         | Son pour lettre incorrecte         | MP3 court (< 1s)  |
| click.mp3         | Son de clic bouton (optionnel)     | MP3 court (< 0.5s)|

## Sources libres de droits recommandées
- https://pixabay.com/fr/music/
- https://freesound.org/
- https://soundbible.com/

## Note
Tous les fichiers audio sont **optionnels**.
Le jeu fonctionne parfaitement sans eux.
